So... What's Blove?
-
Blove is a student-powered learning platform designed to help students share and access study resources more easily. 
Some of its key features include a test and exam resource hub, built-in study tools, and a rewards system called Blove Points that encourages engagement and collaboration.
-----

Download the project as a Zip, unzip it on your computer, and import the project (from Zip) into NetBeans.
Alternatively, you can move the unzipped project into your NetBeans Project folder and open it in NetBeans.

To run the application:
src --> accountGUI --> LoggedOutMainGUI (form)

*Note: It SHOULD automatically open this form if you run the project, but in the case that it DOESN'T, please find and run the form written above.
